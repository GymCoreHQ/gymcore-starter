# GymCore Starter brief

Build a reusable WordPress block theme and independent optional companion plugin for martial arts schools. Private GymCoreHQ review first; potential directory release only after the documented gates pass.

Theme: core blocks, templates, patterns and global styles. Plugin: opt-in fictional draft setup, conservative reset and a server-rendered weekly GymCore class schedule. No transactions, membership mutations, lead collection, remote API calls, custom database tables, cron, checkout replacement or licensing logic. Core WordPress is sufficient for the theme and setup; GymCore is optional for schedule data, and WooCommerce is separately optional for commerce or required by the selected GymCore package.

Minimum target WP 7.0 / PHP 8.3. Current-version and runtime results are recorded separately in docs/verification.md. HPOS, Cart/Checkout Blocks and product editor are not modified, so broad commerce compatibility declarations are intentionally withheld pending testing. Public content remains editable via native WordPress controls.

High-risk plan hardening: skipped for local, reversible development with synthetic data. Repository is private, no deployment or financial operation is in scope. Push requires sanitized artifact audit; no source history is copied.

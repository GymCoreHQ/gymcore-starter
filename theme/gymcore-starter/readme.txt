A native block theme with editable patterns, navigation, and dark and light styles for training communities. No plugins required.

== Description ==
A core-only block theme for training communities. No external fonts, images, scripts,
tracking, custom post types, or plugin dependency. All bundled text is generic starter
instructional copy. It makes no claims about a school or an integration.

== Setup ==
Install and activate the theme, then open Appearance > Editor. Set your site title in
Settings > General and upload your own logo using the Site Logo block. The title stays
visible with or without a logo. Edit Navigation in the header; the initial Home link
uses your site address. Review it before launch. The native mobile overlay supplies the
menu behavior. There is no custom menu script.

The Front Page template contains editable starter patterns. Customize these through
Appearance > Editor > Templates > Front Page. This template controls the front of the
site whether Settings > Reading uses posts or a static page. To manage homepage copy
through the ordinary page editor instead, replace the Front Page template's main
content with a Post Content block and choose a static page in Settings > Reading.
For a posts-only homepage, replace the Front Page template with a Query Loop, or use
the Home/Index template layout. Ordinary pages use their own title and content.

Replace every instructional paragraph. Link programs and booking buttons to your own
published pages or sections. Set contact details in the Contact pattern, insert approved
photos with the Image block, and add social links to the Footer. Patterns are copies;
editing one does not rewrite previously inserted content. Create a synced pattern in
WordPress when shared content is desired. Manage colors, typography, widths, spacing,
and the Light variation through Editor > Styles. No source edits are needed for normal
site content, templates, navigation, or branding.

== Ownership and lifecycle ==
This theme owns presentation only. Business capabilities and integrations belong in
plugins. Deactivation never deletes content. WordPress keeps user-edited templates and
styles in its database; these may override future theme files. Export editor changes or
back up the database before resetting customizations or upgrading. Uninstalling theme
files does not remove posts, pages, uploaded media, or plugin records.

== Accessibility and release status ==
Native landmarks, core mobile navigation, readable color presets, visible focus, and
reflowing layouts are provided. Site authors must supply useful alt text, real link
labels, sensible headings, and accessible plugin content. This theme has not earned
WordPress.org accessibility-ready review. No WordPress.org approval is claimed.
The repository release checklist and runtime test report record actual tested
versions. Verify those before publication. A fictional 1200 by 900 screenshot is
included. Authenticated submission access and directory review remain release gates.
Have a fluent reviewer check any additional translations before shipping them.
No third-party assets or fonts are bundled.
